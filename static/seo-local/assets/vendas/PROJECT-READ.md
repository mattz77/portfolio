# Projeto e escolha

Landing HTML estática da NiceByte para donos de negócios locais brasileiros. Conversão: pedir raio-x gratuito em página própria. Preservar IDs, data-copy, mapa, calculadora, scripts, fontes e tokens existentes. Paleta: creme `--paper`, tinta `--ink`, lima `--lime`; display Oswald, corpo DM Sans. Mobile, peso e acessibilidade dominam.

Design Read: página de vendas para donos de negócios de bairro, editorial de rua, identidade NiceByte. Variance 6: fotos reais e grade assimétrica; motion 5: mapa e timeline já existentes; density 5: cards curtos, hierarquia concreta. Catálogo: Cult UI `feature-sticky-section` (MIT/free) visto no preview. Rejeitado para inserção: seu menu lateral e runtime React duplicariam mapa sticky e custariam JS. Aproveitar só princípio de cena sticky no mapa já implementado, sem copiar fonte. Skiper Timeline Calendar premium rejeitado por licença. CSS nativo para cartões, faixa fotográfica e linha de processo.
