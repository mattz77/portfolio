# Leitura do projeto

Página estática de conversão da NiceByte para comerciantes locais. HTML com CSS inline e JS de formulário existente; recursos compartilhados em `/assets/v2/`, logo a captura precisa servir `static/` como raiz. Tokens observados: papel #f6f5ed, tinta #17251d, lima #d4f164; tipografia Oswald e DM Sans locais. Preservar IDs e nomes do formulário e script. Sem dependências novas e sem efeito que esconda conteúdo sem JS. Foto documental Pexels demonstra público real; timeline compacta traduz a entrega. Catálogo: `Timeline calendar` da Skiper é premium sem licença, descartado; `text-animate` da Cult é MIT, mas exige React/shadcn incompatível com HTML estático. Implementação nativa CSS com IntersectionObserver pequeno, inspirada em progressão por etapas; sem fonte de componente copiada.
